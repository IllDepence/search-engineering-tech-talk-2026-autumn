\begin{frame}[t]{見送った試み：Agents SDKなしのAgentic RAG}
    \only<1-4>{
    \begin{itemize}
        \item 事前検索だけで回答できるケースに最適化
        \onslide<2->{\item Agents SDKなし：ツールなしの普通のLLM呼び出し
        \begin{itemize}
            \item 「ツールを呼ぶか」の推論が不要
            \item ツール定義の分、入力が短い
            \item reasoning\_effort minimalが使える
